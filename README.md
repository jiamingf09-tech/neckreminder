# NeckReminder

一个轻量的 macOS 菜单栏应用：**准确判断你是否在连续使用电脑**，到点后通过系统通知和（可选的）半透明全屏提示提醒你放松颈椎，并内置 2 / 5 / 10 / 15 / 30 分钟的颈椎舒缓跟练指南。

- 原生 Swift（AppKit + SwiftUI），无第三方依赖，单一 **Universal** 二进制（Apple Silicon + Intel），支持 macOS 13 Ventura 及以上。
- **只需要“通知”一项权限**（可选的蓝牙耳机判断另需“蓝牙”权限）。不需要辅助功能、输入监控、屏幕录制、摄像头或麦克风权限；只在打开示范视频时访问 YouTube。
- **会学习你的习惯**：回到电脑时偶尔问一句“刚才是在使用电脑还是离开了”，在本机训练一个小模型，越用越准。

## 功能

| | |
|---|---|
| 智能判断连续使用 | 只看真实的键盘 / 鼠标 / 触控板输入和锁屏状态，详见下文 |
| 提醒间隔 | 15–120 分钟可选（默认 30 分钟），未处理时每 N 分钟再次提醒 |
| 系统通知 | 带操作按钮：放松颈椎 / 5 分钟后 / 10 分钟后 / 本次忽略 / 今日忽略 |
| 全屏提醒（可选） | 关闭 / 当前活跃显示器 / 所有显示器；**半透明、点击穿透、不抢焦点**，大号文字；按钮：5 分钟后提醒、10 分钟后提醒、本次忽略、今日忽略，以及更大的“放松颈椎” |
| 放松颈椎 | 礼炮动画 → 打开应用内舒缓指南，按可用时间选 2 / 5 / 10 / 15 / 30 分钟方案，逐步计时、提示音、可选语音播报；示范视频在应用内播放 |
| 动作库 | 38 个动作（颈部活动 / 拉伸 / 力量、肩部、上背胸椎、眼睛手腕、走动），可搜索；每个动作可直接“练习”或“加入组合” |
| 推荐组合 | 按“热身 → 颈部 → 肩部 → 上背 → 收尾”的结构，从动作库里挑最近没做过的动作，每次不同，可“换一组”；也保留经典固定方案 |
| 我的组合 / 我的动作 | 自定义组合（选动作、时长、拖动排序）；新建自己的动作，可以库中动作为模板，同样有计时、左右切换和示范视频 |
| 动作衔接 | 每个动作前 5–15 秒（默认 8 秒）准备时间，先看清怎么做；语音播报默认关闭，跟练时一键开关 |
| 放松时防“偷偷干活” | 跟练期间在其他应用里持续操作约 10 秒，会暂停计时并弹出全屏提示：回到颈椎放松 / 暂停颈椎放松 / 取消本次放松。中途取消不会算作休息 |
| 回到电脑时的提问 | 右下角小窗：“刚才 9 分钟没有操作 · PowerPoint — [使用电脑] [离开了]”，只在拿不准时出现，不抢焦点，20 秒自动消失，回答立即修正计时 |
| 「还在看吗？」轻提示 | 拿不准时在角落淡出，动一下鼠标即可确认，无需点击 |
| 回顾 | 每天的时间线（使用 / 阅读观看 / 离开 / 放松）和所有较长的无操作时段，一键纠正；显示学习情况和判断正确率 |
| 阅读 / 开会模式 | 菜单栏一键：30 分钟 / 1 小时 / 2 小时内不判定离开 |
| 蓝牙耳机（可选） | AirPods 等信号逐渐减弱后断开 → 判定离开；强信号下断开（放回耳机盒、切到 iPhone、手动断开）不算 |
| 文字大小 | 设置中可调 90%–175%，放松跟练页面有 A− / A+ |
| 时间安排 | 按星期几跳过；多个免打扰时段（支持跨夜，如 22:00–08:00）；临时暂停 30 分钟 / 1 小时 / 2 小时 / 到明天 |
| 菜单栏 | 图标 + 可选倒计时；快速放松、重新计时、暂停 |

| 单实例 | 重复打开不会启动第二份，只会把已运行实例的主界面调出来 |
| 统计 | 今日使用时长、最长连续使用、提醒次数、完成放松次数、自然休息次数、最近 7 天柱状图 |
| 开机自启 | `SMAppService`，状态始终从系统读取 |
| 语言 | 简体中文 / English / 跟随系统 |

## 如何判断“正在连续使用电脑”

这是整个应用最关键的部分，目标是**少误报**：人走了不要算，人在看东西不要漏。

**信号（除可选的蓝牙外，全部无需权限）**

1. `CGEventSource.secondsSinceLastEventType(.hidSystemState, …)`：距离上次**硬件**输入的秒数，分别读取“任意输入”“按键”“点击 / 滚动”。只告诉“多久之前”，不告诉“按了什么”；`.hidSystemState` 会忽略软件模拟的事件。
2. 锁屏、屏幕保护、显示器休眠、系统睡眠、快速切换用户。
3. 前台应用，以及它是否铺满整个屏幕（演示 / 全屏视频）。只读窗口位置和所属进程，不读标题和内容，因此不需要屏幕录制权限。
4. 视频：保持屏幕常亮的电源断言（窗口播放也算，不要求全屏；`caffeinate`、Amphetamine 等防休眠工具被排除）。
5. 画中画：屏幕上小尺寸、悬浮置顶、且对应应用正在出声或保持屏幕常亮的窗口，或系统画中画服务的窗口。
6. 声音：哪个应用正在出声（macOS 14.2+ 精确到应用）。只有声音没有画面（听歌）单独作为一种场景。
7. 麦克风 / 摄像头“是否正被其他应用使用”（菜单栏橙点 / 绿点背后的状态，从不录音录像）：
   摄像头在用 → 视频通话；麦克风 + 会议应用或保持屏幕常亮 → 会议；只有麦克风 → 语音通话（不需要看屏幕，不延长判断）。
8. 最近 5 分钟的输入密度和打字比例（区分写作与阅读）。
9. 可选：蓝牙耳机信号强度趋势与断开。

**基础状态机**（每 5 秒采样，见 `Sources/NeckReminderCore/UsageTracker.swift`）

- 只有真实输入是“在场”的证据；后台编译、下载、播放本身不会让计时增长。
- 短时间无输入算“阅读 / 观看”，这段时间先**暂记**；再次操作时确认计入，一直不动则判定离开并**扣除**暂记时间。
- 锁屏、睡眠、屏保、显示器休眠 → 立即离开。离开不足“休息阈值”（默认 5 分钟）只暂停计时，达到则清零。
- 离开后单次轻微的鼠标移动不算回来；需要按键 / 点击 / 滚动，或连续两次采样都有移动。
- 到点时如果你正在安静阅读，提醒等你下一次操作时再出现。

**学习（`Sources/NeckReminderCore/PresenceModel.swift`）**

“没有操作多久算离开”不再是固定值，而是一个本机的小型逻辑回归模型给出的：在当前场景下（前台应用、视频 / 画中画 / 只有声音、通话类型、全屏、最近的打字和输入密度）沉默 *t* 秒后你仍在使用电脑的概率，概率降到 50% 的时刻就是离开阈值。

- 先验与设置一致：没有任何反馈时，行为与“阅读宽限 3 分钟 / 视频 20 分钟”的规则完全相同。
- 每个应用有自己的偏置项：PowerPoint 里不动 10 分钟和 Finder 里不动 10 分钟含义不同。
- 训练数据：你在提问小窗或回顾页里的回答（权重最高）、轻提示后动了鼠标、以及无需询问就能推断的情况（锁屏 / 睡眠 = 离开；短暂停顿后在同一应用继续 = 在用）。
- 只在模型拿不准（概率在 20%–80% 之间）时提问，每天有上限；演示或全屏时不弹，留到回顾页。
- 安全边界：锁屏、睡眠等仍是硬规则；阈值被限制在 1–60 分钟内；可以随时在回顾页清空学习数据。

设置页的“实时检测状态”面板会显示每个信号的当前值、当前学到的离开阈值和“仍在使用”的概率。

## 权限说明（避免“授权了却显示未授权”）

- 必需的只有通知权限。首次启动请求一次；之后每次应用回到前台、打开设置页都会**重新从系统读取**授权状态，在“系统设置 › 通知”里打开后立即生效。
- 通知不可用且全屏提醒关闭时，会自动改用全屏提醒，保证提醒不丢失。
- 刻意**没有**使用事件监听（`CGEventTap` / `NSEvent` 全局监听），因此不会触发“辅助功能 / 输入监控”授权。
- 蓝牙权限只在开启“蓝牙耳机判断”后才会请求。macOS 按**签名身份**记住这类权限：ad-hoc 签名每次构建都会变，更新后就会出现“授权了却不认”。解决办法见下面的“免费的自签名证书”。

## 构建

需要 macOS + Xcode 15 或更高版本。

```bash
swift test                     # 核心算法单元测试
scripts/build-app.sh           # 生成 dist/NeckReminder.app（universal，ad-hoc 签名）
scripts/make-dmg.sh            # 打包 dist/NeckReminder.dmg
open dist/NeckReminder.app
```

`VERSION`、`BUILD_NUMBER`、`CODESIGN_IDENTITY` 环境变量可覆盖版本号与签名身份。

### CI/CD

`.github/workflows/build.yml` 在 `macos-15` 上运行：单元测试 → 构建 **一个 universal 包**（`lipo` 校验同时包含 arm64 与 x86_64）→ 产出 `.dmg` 与 `.zip` 构件。推送 `v*` 标签（如 `v1.0.0`）会自动创建 GitHub Release。

每次推送后，清理任务只保留最新一次构建的产物和最近 5 次运行记录，产物 7 天后自动过期。

### 免费的自签名证书（推荐，让蓝牙等权限在更新后仍然有效）

不需要 Apple 开发者账号：

```bash
scripts/create-signing-cert.sh            # 生成 signing-cert/cert.p12，并打印三个 Secret 的值
```

把打印出的 `MACOS_CERTIFICATE_P12`、`MACOS_CERTIFICATE_PASSWORD`、`MACOS_SIGNING_IDENTITY` 添加到仓库 Secrets，之后所有构建都用同一个证书签名，macOS 授予的权限会一直保留。首次打开仍需右键 → 打开（只有付费的 Developer ID + 公证能去掉这一步）。
在 Actions 里手动运行 Build 工作流并勾选 “verify_self_signed”，可以用一次性证书完整验证这条签名流程。

### Developer ID 签名与公证（可选，需要付费账号）

配置以下仓库 Secrets 即启用 Developer ID 签名与公证，否则为 ad-hoc 签名：

| Secret | 说明 |
|---|---|
| `MACOS_CERTIFICATE_P12` | Developer ID Application 证书 .p12 的 base64 |
| `MACOS_CERTIFICATE_PASSWORD` | .p12 密码 |
| `MACOS_SIGNING_IDENTITY` | 如 `Developer ID Application: Your Name (TEAMID)`（自签名时为证书名称） |
| `NOTARY_APPLE_ID` / `NOTARY_PASSWORD` / `NOTARY_TEAM_ID` | 公证用 Apple ID、App 专用密码、Team ID |

未公证的构建首次打开时，请右键 → 打开，或执行 `xattr -dr com.apple.quarantine /Applications/NeckReminder.app`。
